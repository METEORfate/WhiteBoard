# 协作白板

多人实时协作白板，支持离线编辑。零运行时依赖，Node.js ≥ 20。

在线演示：<https://whiteboard.dree.shop>

本地运行：

```bash
node server/index.js
```

打开 http://localhost:8787，创建房间后把地址栏链接发给其他人即可协作。断网时继续画，恢复后自动补齐。

## 目录

```
server/     HTTP 入口、房间状态、JSONL 持久化、RFC 6455 实现、静态资源
shared/     协议与合并规则（浏览器与 Node 共用）
client/     画布、交互、网络、本地文档、光标、界面
tests/      单元与集成用例
scripts/    端到端脚本、测试报告生成
data/       运行时数据（不纳入版本管理）
```

## 测试

```bash
npm test          # 14 个文件、96 个用例
npm run e2e       # 两个真实浏览器标签页，需本机 Chrome
```

## 限制

单进程内存态，只适合单实例部署。无鉴权，房间号即访问凭证。
