## 五、关键回归用例

以下用例是为两个「单测全绿但线上必炸」的真实缺陷补的回归，属于本项目的红线：

| 缺陷 | 现象 | 回归用例 |
| --- | --- | --- |
| 握手 GUID 常量写错 | 自研客户端能连，任何真实浏览器握手被拒 | `ws.test.js` — RFC 6455 官方向量 + Node 内置 `WebSocket` 真客户端握手 |
| 合并函数用错语义 | 浏览器里实时同步静默失效，控制台报 `Cannot convert undefined or null to object` | `client-store.test.js` — 远端 shape 合并路径 |

## 六、如何复现

```bash
npm test          # 仅单元 / 集成用例
node scripts/e2e.mjs   # 浏览器端到端（需本机安装 Chrome）
npm run report    # 重新生成本报告
```

测试数据目录由 `tests/helpers.js` 为每个用例创建独立的临时 `DATA_DIR`，用例之间互不影响，也不会污染仓库里的 `data/`。
