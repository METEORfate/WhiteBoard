# 白板项目：部署、运行与测试

## 环境要求

Node.js ≥ 20。无第三方依赖，不需要 `npm install`，没有构建步骤。

## 本地运行

```bash
cd whiteboard
node server/index.js          # 或 npm start
```

默认监听 `0.0.0.0:8787`，启动日志打印实际地址与 bootEpoch。

访问 `http://localhost:8787` 进入落地页，可创建房间或粘贴链接加入。地址带 `?room=<id>` 直接进入白板，分享链接与刷新都走这条路径。

指定端口：

```bash
PORT=9000 node server/index.js          # bash
$env:PORT=9000; node server/index.js    # PowerShell
```

端口被占用时默认向后顺延，最多 10 个（8787 → 8797），全部占用才退出并打印排查命令。设 `STRICT_PORT=1` 关闭顺延，冲突即失败。`PORT=0` 交给系统分配。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | 8787 | 监听端口 |
| `HOST` | 0.0.0.0 | 监听地址 |
| `DATA_DIR` | `./data` | 房间日志目录 |
| `STRICT_PORT` | 未设 | 设为 `1` 时端口冲突直接退出 |
| `ROOM_TTL_MS` | 1800000 | 空房间在内存中的保留时长（30 分钟） |
| `MAX_ROOMS` | 500 | 内存驻留房间上限 |
| `ROOM_CREATE_PER_HOUR` | 60 | 单 IP 每小时建房上限 |
| `ROOM_PROBE_PER_MIN` | 30 | 单 IP 每分钟房间探测次数 |
| `NODE_ENV` | 未设 | 设为 `production` 时禁用 `/api/stats` |
| `WB_QUIET` | 未设 | 设为 `1` 时只输出 error 级日志 |

## 数据

每个房间一个文件：`data/<roomId>.jsonl`，追加写，超过 500 行压缩成快照。`data/` 已在 `.gitignore` 中。

清空某个房间：停服后删除对应 jsonl。清空全部：删除 `data/` 目录。

备份即复制 `data/` 目录。恢复时放回同一路径，下次有人进入房间会自动加载。

## 生产部署

服务是常驻 Node 进程，同时提供 HTTP 与 WebSocket，不能作为静态站点托管。

仓库根目录的 `render.yaml` 已声明 Render 免费 Web Service：

| 配置项 | 值 |
| --- | --- |
| 运行时 | Node.js 22 |
| 构建 | `node --test "tests/*.test.js"`（测试不过则不部署） |
| 启动 | `node server/index.js` |
| 健康检查 | `/healthz` |
| 环境变量 | `NODE_ENV=production`、`HOST=0.0.0.0`、`STRICT_PORT=1` |

`STRICT_PORT=1` 是必须的：平台会把流量打到指定端口，自动顺延会让平台连不上。

免费实例的约束：不挂载持久磁盘，休眠、重启或重新部署会丢失 `data/` 下的房间日志；连续 15 分钟无请求可能休眠，再次访问需约一分钟唤醒。

自定义域名在平台侧添加后，DNS 建 CNAME 指向平台分配的主机名，代理状态选 DNS only。HTTPS 由平台证书提供，客户端会自动使用 `wss://`。

## 测试

### 单元与集成

```bash
npm test
```

等价于 `node --test "tests/*.test.js"`。14 个测试文件、96 个用例，零依赖，每个用例使用独立的临时 `DATA_DIR`，互不干扰，也不污染仓库的 `data/`。

覆盖范围：合并规则与收敛性、协议校验与边界、WebSocket 握手与关闭码、双端同步与房间隔离、离线重连与队列重放、限流与 ack 超时、房间回收与建房配额、崩溃重启恢复。

### 端到端

```bash
npm run e2e
```

需要本机安装 Chrome 或 Edge。脚本通过 `CHROME_PATH` 查找浏览器，找不到会报错并提示指定路径。

默认连 `http://127.0.0.1:8787`；该地址没有服务时，脚本会自动起一个临时服务端（临时 `DATA_DIR`，跑完删除）。

```bash
node scripts/e2e.mjs --url http://127.0.0.1:8787 --out docs/screenshots
```

`--url` 指定被测实例，`--out` 指定截图输出目录。脚本用裸 CDP 驱动两个标签页，覆盖双端同步、断网继续绘制、重连后状态一致、并发改不同字段、画笔同步、导出 PNG，共 21 项检查。

断网通过在页面与服务器之间挂可控 TCP 代理实现：切断时 RST 在途连接并拒绝后续连接，因此断网期间的重连是真的失败，恢复后是真的重连。

### 测试报告与格式

```bash
npm run report     # 逐文件跑 junit，生成 docs/测试报告.md
npm run format     # prettier 格式化，走 npx，不写入依赖
npm run format:check
```

## 启动异常排查

`EADDRINUSE`：上一个实例未退出。结束占用进程或换端口：

```powershell
Get-NetTCPConnection -LocalPort 8787 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }
```

页面白屏或改代码不生效：浏览器缓存了旧 ES Module，`Ctrl+Shift+R` 强刷；仍异常则看控制台是否有 404。

两个窗口看不到对方的图形：检查顶部状态条是否为「已连接」，再看调试面板的「模拟断网」是否被勾选。

`/api/stats` 返回 403：该接口仅在本机访问且非 production 环境开放。
